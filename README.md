# ⚡ Abaddon Master Nexus (Supreme Hybrid & Cloud App Forge)

> **منصة هندسية متكاملة لربط الذكاء الاصطناعي، قواعد البيانات السحابية، والتطوير الهجين مع محرك بناء APK آلي عبر سحاب GitHub Actions.**

---

## 🚀 نظرة عامة على النظام (Overview)
**Abaddon Master Nexus** ليس مجرد محرر أكواد، بل هو بيئة سيطرة وتشغيل متزامنة تتيح لك:
1. **الربط المركزي (API Nexus):** ربط متزامن مع نماذج الذكاء الاصطناعي (`Gemini` / `Claude`)، قواعد بيانات `Supabase` (بصلاحيات كاملة)، ومستودعات `GitHub`.
2. **إدارة تطبيقات مزدوجة (Dual Apps Engine):** تطوير التطبيق الأول والثاني بالتوازي مع إمكانية التشغيل الفعلي (`Run`) ومعاينة التفاعل المباشر.
3. **التعديل الذكي التلقائي (AI Modifiers):** اختيار النماذج المتقدمة وكتابة الأوامر ليقوم النظام بحقن وتعديل الأكواد تلقائياً وبدون أخطاء.
4. **المفاعل السحابي (GitHub Actions APK Forge):** بناء وتصدير حزم تطبيقات أندرويد حقيقية (APK) سحابياً دون الحاجة لأجهزة قوية محلياً.
